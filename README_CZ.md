# Hacesoft FamilyTree – Rodokmen pro Nextcloud

**Česky** · [English](README.md)

**FamilyTree (Rodokmen)** je genealogická aplikace pro Nextcloud. Umožňuje vytvářet a procházet rodokmeny, zaznamenávat rodinnou historii, spravovat fotografie a prameny a spolupracovat s dalšími uživateli Nextcloudu.

## Co aplikace umí

- **Rodokmeny a osoby:** interaktivní zobrazení stromu, příbuzenské vztahy, životní události, poznámky a detaily osob.
- **Fotografie a dokumenty:** galerie fotografií osob, ořez a otočení portrétů, pramenné dokumenty a archivní materiály.
- **Genealogické bádání:** výzkumný deník, důkazy, citace, úkoly, vyhledávání a statistiky rodokmenů.
- **Import a zálohování:** import GEDCOM 7 / GEDZIP, doplňování badatelských nálezů do existujících rodokmenů a úplná záloha s obnovou.
- **Sdílení a vlastnictví:** oprávnění uživatelů a skupin Nextcloudu včetně možnosti předat rodokmen novému vlastníkovi.
- **Osobní nastavení:** vlastní pořadí rodokmenů, volba úvodního rodokmenu a widget na nástěnce s posledními změnami.
- **Pohodlné používání:** rozhraní pro počítače i mobilní zařízení a podpora více jazyků.
