# Rodokmen 1.2.1 — noční test metadat

**Není určeno pro produkci.** Aplikace má stejné ID `hc_familytree` jako produkční rodokmen, ale všechny genealogické funkce nahrazuje dvojjazyčnou informační obrazovkou. Testují se pouze metadata a screenshoty App Store a deklarace NC34–NC35. Skutečná funkčnost na NC34 se tím nedokazuje. Aplikace záměrně nemění rodinná data. Produkční zálohy zachovejte.

Původní ikona a URL screenshotů jsou bitově či textově převzaty z FamilyTree 1.2.0.

Sestavení: `sh build-release.sh`. Zdrojový ZIP je určen Publisheru, nepodepsané balíky nezveřejňovat.
