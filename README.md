# Hacesoft FamilyTree – Genealogy for Nextcloud

**English** · [Česky](README_CZ.md)

**FamilyTree** is a genealogy application for Nextcloud. Build and explore family trees, document family history, organize photographs and sources, and work with other Nextcloud users in one place.

## Features

- **Family trees and people:** interactive tree views, family relationships, life events, notes and person details.
- **Photos and documents:** personal photo galleries, portrait cropping and rotation, source documents and archival materials.
- **Genealogy research:** a research journal, evidence, citations, tasks, searches and tree statistics.
- **Import and backup:** GEDCOM 7 / GEDZIP import, incorporation of research findings into existing trees, and native backup and restore.
- **Sharing and ownership:** access permissions for Nextcloud users and groups, including transfer of a tree to a new owner.
- **Personal workspace:** arrange your tree list, choose a startup tree and use the Nextcloud dashboard widget for recent changes.
- **Everyday use:** responsive layout for desktop and mobile devices, with a multilingual interface.
