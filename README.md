# FamilyTree 1.2.1 — Nightly metadata test

**Not for production.** This application shares the production `hc_familytree` ID but replaces all functional genealogy code with a bilingual warning page. This package tests App Store screenshots and NC34–NC35 metadata only. It does not prove NC34 runtime compatibility. It never intentionally modifies family data. Keep production backups.

Original icon and screenshot URLs are retained verbatim from FamilyTree 1.2.0.

Build `sh build-release.sh`; send the source ZIP to the Hacesoft Publisher. Never publish the unsigned staging archive.
