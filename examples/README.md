# Charles IV sample family tree

**Language:** English · [Česky](README_CZ.md)

This directory is intended for a public **Charles IV sample family tree**, allowing users to try the import workflow in [FamilyTree](../README.md).

The sample family tree file in `.ged` or `.gdz` format is published separately in this directory. If no file is listed, it has not been uploaded yet.

## How to import the sample tree

1. Once published, download the sample `.ged` or `.gdz` file from the `examples/` directory.
2. Open **FamilyTree** in Nextcloud.
3. Select **⋯ → Import family tree / backup**.
4. Choose **GEDCOM 7 / GEDZIP** and upload the downloaded file.
5. Review the import preview and choose to create a **new tree** for demonstration.

**Note:** GEDCOM/GEDZIP is a genealogy exchange format, not a complete native FamilyTree backup. Sample data is for demonstration and should not automatically be treated as historically verified.

More details: [Import/export guide](../docs/en/IMPORT_EXPORT_BACKUP.md).
