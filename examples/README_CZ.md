# Vzorový rodokmen Karla IV.

**Jazyk:** [English](README.md) · Česky

Tato složka je určena pro veřejný **ukázkový rodokmen Karla IV.**, na kterém si mohou uživatelé vyzkoušet import do aplikace [FamilyTree](../README_CZ.md).

Soubor vzorového rodokmenu ve formátu `.ged` nebo `.gdz` se zveřejňuje samostatně v této složce. Pokud jej zde ještě nevidíte, nebyl zatím přidán.

## Jak ukázkový rodokmen naimportovat

1. Po jeho zveřejnění si ze složky `examples/` stáhněte ukázkový soubor `.ged` nebo `.gdz`.
2. V Nextcloudu otevřete aplikaci **Rodokmen**.
3. Zvolte **⋯ → Import rodokmenu / zálohy**.
4. Vyberte **GEDCOM 7 / GEDZIP** a nahrajte stažený soubor.
5. Před potvrzením zkontrolujte náhled importu a pro testování zvolte vytvoření **nového rodokmenu**.

**Pozor:** GEDCOM/GEDZIP je výměnný genealogický formát, nikoli úplná nativní záloha aplikace. Ukázková data slouží k demonstraci a nelze je automaticky považovat za historicky ověřená.

Podrobnosti: [Import a export – český návod](../docs/cz/IMPORT_EXPORT_ZALOHA.md).
